# Global Food Market

A complete, responsive website for Global Food Market, an international grocery store in Lansing, Michigan.

## Run locally

Open `index.html` directly in a browser, or serve the project folder with any static web server.

## Files

- `index.html` - Page content, SEO metadata and structured data
- `style.css` - Responsive premium grocery store design
- `script.js` - Navigation, reveal animations, gallery lightbox and contact form behavior
